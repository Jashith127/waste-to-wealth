# Audio

Drop recordings here with the file names in `src/data/audio.json`. A sound plays from its file as soon as the
file exists; until then, effects are synthesised in the browser and ambient beds are silent.

- **Ambient beds** (`ambient_market.ogg`, `ambient_street.ogg`, `ambient_plant.ogg`): ambient sections only of
  our own field recordings, with **no identifiable voices** (spec). Loop-ready, about 30–60 s, Ogg Vorbis.
- **Effects** (`cleaver.ogg`, `scale.ogg`, `door_seal.ogg`, `upi_ping.ogg`, …): short, dry, under 1 s.
